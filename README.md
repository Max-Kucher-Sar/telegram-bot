# telegram-bot
Данный Telegram-bot может вывести информацию о себе, предоставить формулу рассчета каллорий 
и рассчитать норму калорий для мужчины.
Также реализована функция просмотра доступных товаров с их описанием и возможностью купить
товар на выбор.
Реализован процесс идентификации пользователя с помощью класса State библиотеки aiogram.
Данные о пользователе сохранялись во встраиваемую реляционную базу данных - SQLite3.
